## 1. Daily digest markdown

### 1) [joulupukki/Flick](https://github.com/joulupukki/Flick) — **PASS**

A nicely focused Daisy pedal project: reverb, tremolo, and delay on Daisy Seed, targeting both FunBox and Hothouse-style platforms. What pushes it above “yet another pedal” is the control design: tap-tempo mode, reverb edit mode, settings mode, save/cancel behavior, and explicit parameter-capture logic to prevent jumps when re-entering hidden pages. That is extremely reusable UI/firmware craft for small-control embedded pedals. The repo also documents a fresh demo dated **March 18, 2026**.  
Sources: [repo README](https://github.com/joulupukki/Flick), [Daisy forum noise/debug thread mentioning the repo](https://forum.electro-smith.com/t/daisy-seed-6khz-oscillation-noise-in-multi-effects-pedal-flick/9084)

### 2) [Orastron/brickworks](https://github.com/Orastron/brickworks) — **REF_PASS**

This is one of the best “steal the architecture, not the product” finds in the Daisy orbit. Brickworks is a cross-platform music DSP toolkit with examples for VST3, LV2, Web Audio, command line, mobile, and notably **Daisy Seed**. The repo’s **v1.4.0 release on October 23, 2025** and the Daisy forum thread make it relevant here: it gives you portable building blocks plus Daisy examples without locking you into a board-specific firmware architecture.  
Sources: [repo](https://github.com/Orastron/brickworks), [Daisy forum thread](https://forum.electro-smith.com/t/daisy-seed-support-added-to-orastron-brickworks-dsp-library/3505)

### 3) [alex6679/teensy-4-usbAudio](https://github.com/alex6679/teensy-4-usbAudio) — **REF_PASS**

Strong PJRC-side infrastructure pick. This extends Teensy 4.x USB audio from basic stereo toward **2/4/6/8-channel UAC2 I/O**, with configurable sample rates, experimental block sizes, host feedback handling, and Design Tool integration. It is not a turnkey instrument, but it is exactly the kind of foundation repo that can unblock multichannel interfaces, low-latency routing experiments, and more serious host integration on Teensy.  
Sources: [repo README](https://github.com/alex6679/teensy-4-usbAudio), [PJRC forum latest audio-project activity page showing current discussion around multichannel USB audio](https://forum.pjrc.com/index.php?goto%2Fpost=&id=233108)

### 4) [carlvp/daisylab](https://github.com/carlvp/daisylab) — **PASS**

This is a compact but high-yield Daisy repo centered on one especially good idea: `op6daisy`, a **six-operator FM synth** for Daisy that reads and converts Yamaha DX7 bulk dumps, plus a companion `op6-ui` editor/uploader. The Daisy forum thread adds the real substance: by **July 13, 2024** the author had pushed polyphony from 4 to 16 voices, optimized the hot operator loop, and added a USB-vs-UART MIDI build option. High adaptation value if you care about FM-on-M7, SysEx workflows, or split host/device tooling.  
Sources: [repo](https://github.com/carlvp/daisylab), [forum thread](https://forum.electro-smith.com/t/op6-6-operator-fm-synth/5358)

### 5) [rolfdegen/Jeannie-Open-source-Synthesizer](https://github.com/rolfdegen/Jeannie-Open-source-Synthesizer) — **PASS**

More complete product-style than the average Teensy synth repo: 8 voices, dual oscillators per voice, wavetable banks, ladder and SVF filtering, sequencer, SD patch storage, TFT UI, USB SysEx, and a mature hardware control surface. It is not brand new, but it still scores well on utility and adaptability because it combines firmware, interface model, storage, and buildable hardware in one place.  
Sources: [repo README](https://github.com/rolfdegen/Jeannie-Open-source-Synthesizer), [related project discussion context](https://forum.midibox.org/t/teensy-4-1-diy-synthesizer/20985)
