### 2) [`willbearfruits/GlitchPedal`](https://github.com/willbearfruits/GlitchPedal) — **STRONG_PASS**

**Technical summary:** Daisy Seed multi-effects guitar pedal firmware with bypass, overdrive, ReverbSc, chorus, stereo delay, FFT phase-vocoder pitch shift, spectral freeze, and drone. The README states it is fully working and deployed to hardware, with QSPI flash and SDRAM usage documented. fileciteturn18file0L6-L23

**Why it matters:** This is a compact reference for mixing conventional pedal effects with spectral processing on Daisy. The useful engineering value is not only the effect list, but the documented split between a lean audio callback and deferred FFT/control/display work.

**Implementation highlights:**

- Daisy Seed target with QSPI flash configuration.
- Large buffers placed in SDRAM for delay, FFT input/output, ring buffers, and reverb.
- 1024-point FFT, 75% overlap, Hann window, 48 kHz sample rate, and roughly 187 FFT frames/s.
- Real-time-safety notes: no blocking work in audio callback, FFT deferred to main loop, controls at 100 Hz, display at 10 Hz.
- Explicit CMSIS-DSP source-file inclusion and `arm_bitreversal2` assembly symlink workaround. fileciteturn18file0L96-L145

**Platform relevance:** Daisy Seed, Cortex-M7, CMSIS-DSP, QSPI boot, SDRAM buffers, spectral FX, guitar pedals, OLED/pot/footswitch control.

**Adaptation ideas:**

- Use the QSPI/SDRAM placement notes as a Daisy build-size and buffer-placement checklist.
- Extract spectral-freeze and drone architecture for a Daisy Field ambient processor.
- Compare the main-loop FFT split against a strict block-callback STFT implementation.
- Use the build notes as a warning list for CMSIS-DSP integration on Daisy.

**Quick engineering assessment:** Strong promotion from HOLD. I would not blindly trust the README’s performance claims without building/profiling it, but the source structure and documented implementation details clear the digest bar.

**Sources:** [repo](https://github.com/willbearfruits/GlitchPedal), [README](https://github.com/willbearfruits/GlitchPedal/blob/master/README.md)

- Calibration flow for CV/fader/aux ranges and compensation.

### 5) [`raybellis/PicoSynth`](https://github.com/raybellis/PicoSynth) — **REF_PASS**

**Technical summary:** Work-in-progress Raspberry Pi Pico wavetable synth with 128 voices, 16-channel multitimbral behavior, 16-bit stereo I2S at 44.1 kHz, RP2040 interpolator-based wavetable DCOs, per-voice modulation, USB MIDI, serial MIDI, 250 MHz overclocking, Pimoroni Audio Pack support, and Datanoise PicoADK support. fileciteturn20file0L6-L37

**Why it matters:** The interesting idea is high voice count on RP2040 using the hardware interpolator and lookup-table generation. It is not a polished instrument, but it is a useful counterexample to the assumption that Pico-class synths must be tiny monophonic demos.

**Implementation highlights:**

- 128 voices and 16 MIDI channels on RP2040-class hardware.
- 2048-sample 16-bit wavetable DCOs using the RP2040 interpolator.
- I2S audio through Pimoroni Audio Pack assumptions.
- USB MIDI device and UART serial MIDI.
- Build uses Pico SDK, Pico Extras, Pimoroni Pico libraries, and NodeJS-generated lookup tables. fileciteturn20file0L39-L52

**Platform relevance:** RP2040, Raspberry Pi Pico, I2S audio, wavetable synthesis, USB/serial MIDI, embedded lookup-table generation.

**Adaptation ideas:**

- Study interpolator use for wavetable address generation before writing a Pico 2/RP2350 oscillator bank.
- Port a reduced voice engine to RP2350 and compare against the already-published `picoX7` / PRA32-style approaches.
- Use the NodeJS lookup-generation step as a simple offline DSP-table pipeline reference.
- Borrow the multitimbral model for lightweight MIDI sound modules.

**Quick engineering assessment:** REF_PASS, not PASS. The README explicitly marks it as WIP and assumes Pico SDK fluency, so it is best treated as an architecture reference rather than a ready build.

**Sources:** [repo](https://github.com/raybellis/PicoSynth), [README](https://github.com/raybellis/PicoSynth/blob/main/README.md)
