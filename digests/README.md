# Daily digests

This folder stores full Markdown snapshots of the Embedded Audio Mine daily digest.

Naming convention:

```text
digests/YYYY-MM-DD.md
```

The scheduled ChatGPT task should write each future digest here and update `data/published-repo-log.csv` when items are published.

Backfill note: earlier chat-only digests can be added here only when their full Markdown text is available.
