### 1) [`HolyBimBam/xiao-audio-midi-breakout-v1.0`](https://github.com/HolyBimBam/xiao-audio-midi-breakout-v1.0) — **STRONG_PASS**

**Technical summary:** RP2350 audio/MIDI breakout for Seeed Xiao RP2350 with PCM5102A I2S DAC, TRS Type-A MIDI in/out, native USB-C, three pots, two switches, three WS2812 LEDs, a published schematic, and firmware folders for multiple engines. The repository ships a working AMY reference firmware and an actively evolving Synth_Dexed/MSFA DX7 firmware path. fileciteturn56file0L7-L30

**Why it matters:** This is unusually useful because it combines a concrete audio/MIDI front-end board, deterministic pin constraints, panel controls, USB MIDI, TRS MIDI, and real firmware glue. It is a better embedded-audio reference than another naked synth sketch because the board-level constraints and firmware routing are explicit. fileciteturn56file0L32-L58

**Implementation highlights:**

- PCM5102A I2S output on enforced GP2/GP3/GP4 pin mapping.
- TRS Type-A MIDI RX/TX via Serial1, plus USB-C MIDI device support.
- AMY firmware exposes composite CDC + MIDI over Adafruit TinyUSB as `xiao-amy-synth`. fileciteturn57file0L14-L35
- Panel maps pots/buttons into preset selection, cutoff, volume, program changes, and all-notes-off. fileciteturn57file0L36-L60
- AMY presets are tuned around RP2350 budget: four osc-level voices, three built-in DX7 voices, and two custom Cirrus DX7 voices. fileciteturn57file0L61-L75
- Recent Dexed work moved the audio engine/I2S writer to core 1, used an inter-core FIFO for MIDI/preset/filter commands, and documented arduino-pico I2S DMA/jitter workarounds. fileciteturn58file0L1-L27

**Platform relevance:** RP2350, Seeed Xiao, Arduino-Pico, PlatformIO, TinyUSB MIDI, PCM5102A I2S, TRS MIDI, embedded DX7/FM engines, small-panel synth hardware.

**Adaptation ideas:**

- Use the pin map and PCM5102A/no-MCLK constraints as a reference for compact RP2350 synth boards.
- Reuse the TinyUSB CDC+MIDI split for debug plus host-facing MIDI.
- Study the core-0/control and core-1/audio split before doing RP2350 audio with USB and LEDs active.
- Treat the AMY-vs-Synth_Dexed split as a practical comparison of general oscillator engines versus optimized FM engines.

**Quick engineering assessment:** Best item today. The caveats are real: hardware license is still marked TBD, SW1/SW2 require a documented ground bodge, and the Dexed README still contains scaffold-era wording while commit history indicates a later working path. That mismatch is worth verifying before building, but the source detail is strong enough for `STRONG_PASS`. fileciteturn56file0L87-L92 fileciteturn57file0L86-L113 fileciteturn59file0L10-L14

**Sources:** [repo](https://github.com/HolyBimBam/xiao-audio-midi-breakout-v1.0), [AMY firmware](https://github.com/HolyBimBam/xiao-audio-midi-breakout-v1.0/tree/main/firmware/amy), [Dexed firmware](https://github.com/HolyBimBam/xiao-audio-midi-breakout-v1.0/tree/main/firmware/dexed)

### 2) [`ledlaux/vija-pico-synth`](https://github.com/ledlaux/vija-pico-synth) — **PASS**

**Technical summary:** Raspberry Pi Pico / RP2040 / RP2350 digital synth based on the Mutable Instruments Braids macro oscillator in a semi-modular format. It documents 40-plus oscillator engines, OLED UI with oscilloscope mode, two pots, CV input, MIDI CC, SVF filter, USB MIDI, UART MIDI, and an arpeggiator with MIDI sync. fileciteturn39file0L3-L19

**Why it matters:** This is a compact but serious Pico synth target. The interesting value is not only the Braids engine port; it is the complete small-instrument integration: display modes, CV/MIDI mode switching, soft takeover, MIDI CC map, I2S output, and distinct RP2040/RP2350 build settings. fileciteturn39file0L22-L76

**Implementation highlights:**

- Uses arduinoMI / ported STMLIB and BRAIDS libraries.
- Supports RP2040 and RP2350 with different sample-rate/polyphony expectations.
- RP2040 path documents 240 MHz overclock, `-O3`, TinyUSB, 32 kHz for four voices or 44.1 kHz for three voices.
- RP2350 path documents 240 MHz, `-O3`, TinyUSB, and 48 kHz target.
- Wiring notes cover PCM5102 I2S, OLED, encoder, pots, CV inputs, and UART MIDI optocoupler. fileciteturn39file0L99-L163
- Version history marks `v1.0.3` on 2026-04-18 with arpeggiator addition. fileciteturn39file0L173-L177

**Platform relevance:** RP2040, RP2350, Pico, Arduino-Pico, Braids/STMLIB ports, I2S DACs, USB MIDI, UART MIDI, OLED synth UI, CV-to-parameter control.

**Adaptation ideas:**

- Use as a Pico 2 baseline for Braids-style oscillator engines before moving to Daisy/Teensy.
- Reuse the soft-takeover MIDI/CV mode concept for small hybrid controllers.
- Compare RP2040 and RP2350 sample-rate/polyphony limits against the HolyBimBam AMY/Dexed path.
- Borrow the oscilloscope-idle display idea for user feedback on minimal-control instruments.

**Quick engineering assessment:** Strong `PASS`. It is source-available, documented, and recent enough, but I would not call it `STRONG_PASS` because I did not verify prebuilt firmware artifacts or a hardware repo-level PCB package.

**Sources:** [repo](https://github.com/ledlaux/vija-pico-synth)
