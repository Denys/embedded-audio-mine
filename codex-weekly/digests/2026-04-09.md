## Highlights & Reuse Ideas

**1. [pyannote/pyannote-audio](https://github.com/pyannote/pyannote-audio)**

> Neural building blocks for speaker diarization: speech activity detection, speaker change detection, overlapped speech d

Reuse idea: distill/quantize just a lightweight VAD front-end and run it as a “smart gate/ducking” module on STM32H7/ESP32 for voice-controlled eurorack or pedal input.

**2. [korginc/logue-sdk](https://github.com/korginc/logue-sdk)**

> This repository contains all the files and tools needed to build custom oscillators and effects for the prologue synthes

Reuse idea: port one of your favorite algorithms into the logue SDK format as a reference “embedded plugin” architecture, then mirror the same module API on Daisy Seed for cross-platform effects.

**3. [DBraun/DawDreamer](https://github.com/DBraun/DawDreamer)**

> Digital Audio Workstation with Python; VST instruments/effects, parameter automation, FAUST, JAX, Warp Markers, and JUCE

Reuse idea: use it as an offline regression harness for your JUCE plugins, and reuse the same test vectors to validate embedded ports on Teensy/Daisy.

**4. [marcel-licence/ML_SynthTools](https://github.com/marcel-licence/ML_SynthTools)**

> ML_SynthTools

Reuse idea: use it for quick model-in-the-loop synth prototyping on desktop, then export simplified inference (or parameter maps) for Teensy 4.1 wavetable/physical modeling experiments.

**5. [antoinevg/daisy_bsp](https://github.com/antoinevg/daisy_bsp)**

> Board support package for the Electro-Smith Daisy Seed.

Reuse idea: mine the BSP patterns (clocking, codec, DMA audio) to create a minimal, repeatable “audio bring-up checklist” you can reuse on custom eurorack PCBs.

**6. [rheslip/DaisySP_Teensy](https://github.com/rheslip/DaisySP_Teensy)**

> DaisySP Audio DSP Library for the Teensy 4

Reuse idea: standardize DSP building blocks across Teensy and Daisy: write effects once against DaisySP-style APIs, then A/B profile CPU and latency differences.

**7. [zlosynth/kaseta](https://github.com/zlosynth/kaseta)**

> Saturating tape delay and feedback sculptor.

Reuse idea: port the saturation + feedback topology into a compact STM32H7/Teensy delay module with “feedback EQ” and runaway protection for eurorack.

**8. [sourcebox/mi-plaits-dsp-rs](https://github.com/sourcebox/mi-plaits-dsp-rs)**

> Rust port of Mutable Instruments Plaits module DSP code.

Reuse idea: prototype new Plaits-style models safely in Rust, then back-port to C++ for Daisy/Teensy builds.

**9. [kwarc93/audio-multieffect](https://github.com/kwarc93/audio-multieffect)**

> Guitar multi effect running on STM32F746-DISCO board

Reuse idea: lift its audio I/O + effect routing to bootstrap a STM32 “pedalboard” firmware skeleton (bypass, preset switching, UI), then swap in your own algorithms.

**10. [alex6679/teensy-4-usbAudio](https://github.com/alex6679/teensy-4-usbAudio)**

> Extension of the Teensy 4 and 4.1 USB audio input and output.

Reuse idea: build a USB-audio “bridge” tool to stream multichannel audio from a host DAW into Teensy for real-time embedded algorithm tuning before standalone eurorack hardware.
